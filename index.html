# NEXORA — Modern 3D Technology Agency

## Deployment Steps
1. Clone this repository or copy files into your project directory.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to launch local developer preview.
4. Deploy to Vercel via CLI (`vercel`) or continuous integration on GitHub.
